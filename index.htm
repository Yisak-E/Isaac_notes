JavaScript Events

JavaScript events are actions or occurrences that happen in the browser window, which can be detected by JavaScript. These events can be triggered by user interactions, such as clicking a button, moving the mouse, or pressing a key.

Here are some common JavaScript events:

Mouse Events

`click`: Triggered when an element is clicked.
`dblclick`: Triggered when an element is double-clicked.
`mousedown`: Triggered when a mouse button is pressed.
`mouseup`: Triggered when a mouse button is released.
`mousemove`: Triggered when the mouse is moved.
`mouseover`: Triggered when the mouse is moved over an element.
`mouseout`: Triggered when the mouse leaves an element.
`contextmenu`: Triggered when the context menu (right-click) is activated.

Keyboard Events

`keydown`: Triggered when a key is pressed down.
`keyup`: Triggered when a key is released.
`keypress`: Triggered when a key is pressed (deprecated, use `keydown` or `keyup`).

Form Events

`submit`: Triggered when a form is submitted.
`change`: Triggered when the value of an input element changes.
`input`: Triggered while the value of an input element is being modified.
`focus`: Triggered when an element gains focus.
`blur`: Triggered when an element loses focus.

Window Events

`load`: Triggered when the page finishes loading.
`resize`: Triggered when the browser window is resized.
`scroll`: Triggered when the user scrolls the page.
`unload`: Triggered when the user leaves the page.
`error`: Triggered when there is a JavaScript error.

Touch Events (Mobile)

`touchstart`: Triggered when a touch point is placed on the screen.
`touchend`: Triggered when a touch point is removed from the screen.
`touchmove`: Triggered when a touch point moves across the screen.
`touchcancel`: Triggered when a touch event is canceled.

Drag & Drop Events

`drag`: Triggered when an element is being dragged.
`dragstart`: Triggered at the start of dragging.
`dragend`: Triggered when dragging ends.
`dragover`: Triggered when the dragged element is over a valid drop target.
`drop`: Triggered when the dragged element is dropped on a valid target.

Clipboard Events

`copy`: Triggered when content is copied to the clipboard.
`cut`: Triggered when content is cut to the clipboard.
`paste`: Triggered when content is pasted from the clipboard.

Media Events

`loadstart`: Triggered when the browser starts looking for media.
`progress`: Triggered when the browser is downloading media.
`suspend`: Triggered when media download is paused.
`abort`: Triggered when media download is canceled.
`ended`: Triggered when media playback ends.

`timeupdate`: Triggered when the current playback position changes.
`canplay`: Triggered when the browser can start playing media.
`canplaythrough`: Triggered when the browser estimates it can play through the media without stopping.
`playing`: Triggered when media is playing after being paused or stopped.
`waiting`: Triggered when media is paused and waiting for more data.
`seeking`: Triggered when the user is seeking to a new position in the media.
`seeked`: Triggered when the seeking operation is complete.
`stalled`: Triggered when the browser is trying to fetch media but is unable to.
`loadedmetadata`: Triggered when metadata (like duration) is loaded.
`loadeddata`: Triggered when the first frame of media is loaded.
